# Paper source

LaTeX source for *Decay Without Creep: Typed Harness State for Agents That Forget
Knowledge but Not Authority*.

The markdown draft at `../docs/paper/draft.md` is the source of truth: every number in it
comes from `decaymem.report` reading the experiment directories. This directory is the
deterministic last mile.

```
make tex        # regenerate sections/*.tex from the markdown draft
make figures    # regenerate figures/*.pdf from the experiment directories
make pdf        # build/main.pdf                  (needs: brew install tectonic)
make check      # fail on undefined citations, overfull boxes, leftover placeholders
make arxiv      # dist/arxiv-submission.tar.gz, including main.bbl
```

## Before submitting

1. Fill the author name in `main.tex` (`\AuthorName`, `\AuthorEmail`). `make check`
   fails while the placeholders are present.
2. `make arxiv`, then upload `dist/arxiv-submission.tar.gz`.
3. Primary category **cs.AI**, cross-list **cs.CR**.

## Layout

| path | role |
|---|---|
| `main.tex` | preamble, title block, section inputs |
| `sections/*.tex` | generated by `scripts/md2tex.py`; do not hand-edit, edit the markdown |
| `references.bib` | generated from arXiv metadata; titles are double-braced to preserve case |
| `scripts/md2tex.py` | markdown to LaTeX converter (headings, tables, figures, citations) |
| `scripts/citemap.json` | author-year string to BibTeX key |
| `scripts/check.py` | build gate |
| `figures/*.pdf` | copied from `decaymem.report.paperfigs` output |
