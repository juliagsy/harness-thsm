\section{Background and related work}
\label{sec:background-and-related-work}

\textbf{Decay and forgetting for utility.} Ebbinghaus-style exponential decay with reinforcement on access (MemoryBank; FadeMem, \citep{wei2026}), ACT-R base-level activation \citep{anderson1991}, outcome-based Memory Worth \citep{simsek2026}, admission control (A-MAC, Zhang et al. 2026) and constrained-retention formulations \citep{kang2026} share a scoring view of memory in which nothing is protected. The control-plane study \citep{yang2026} observes that production failures are forgetting failures while benchmarks measure recall, and separates a recall plane from a mutation plane, a distinction our operator table adopts.

\textbf{Consolidation and skill libraries.} Continuous consolidation degrades memory utility below the no-memory baseline \citep{zhang2026c}; unbounded skill libraries drift \citep{zhang2026c}; SKILL.nb and SkillOps add lifecycle gating \citep{hattami2026,pu2026}. None separates what a skill does from what it is allowed to do.

\textbf{Authority and constraints.} Progent \citep{shi2025} and SEAgent \citep{ji2026} enforce privilege at the tool boundary; authorization propagation and delegation studies \citep{tallam2026,dantuluri2026} show that authority gated inside the model fails and that ordinary operation, not attacks, produces creep. Authorization Laundering \citep{cerruti2026} names the memory-writer failure we build on. Governance Decay \citep{chen2026} and omission-constraint decay \citep{gamage2026} measure in-context erosion; MemEvoBench and ``Remembering More, Risking More'' \citep{xie2026,altawaha2026} measure safety drift with memory length. The SSGM framework and the Always-On Agents survey \citep{lam2026,ding2026} supply the vocabulary of authority, scope, mutability and provenance, and note that the field studies accumulating state far more than relinquishing it.

\textbf{Gap.} No prior system (a) types harness state, (b) exempts deontic state from decay and consolidation by construction, (c) labels integrity so model-written text cannot create or widen authority, and (d) measures utility and authority on the same traces.
